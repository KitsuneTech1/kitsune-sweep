# Kitsune Sweep 0.1.0 emulator acceptance

Test target: `glass`, Android API 34, x86_64

Host resource limits: 2 emulator cores, 1.5 GB guest RAM, one Gradle worker, 1.5 GB Gradle heap, persistent Gradle and Kotlin daemons disabled.

## Automated coverage

- JVM policy, scanner, duplicate, app inventory, system action, deletion, and ViewModel tests.
- Android MediaStore query and stream tests.
- Android installed-app, usage, and storage source tests.
- Android intent-resolution tests for permissions, settings, app details, and cache clearing.
- Compose tests for honest permission gates, empty states, navigation, disabled deletion, exact selection totals, deletion confirmation, remaining-path reporting, and 200 percent text.

## Acceptance results

| Check | Result | Evidence |
| --- | --- | --- |
| Permission denial | Pass | Files and Duplicates show an All Files Access gate instead of a misleading partial scan. Home and Apps remain usable. |
| Usage Access grant and return refresh | Pass | Granting `GET_USAGE_STATS` through the emulator app-op and recreating the activity refreshed the permission state. |
| Large-file thresholds | Pass | Five threshold chips render at 50 MB through 1 GB; Compose verifies every label stays inside its chip and viewport at 200 percent text. |
| Exact duplicate grouping | Pass | Covered by the connected duplicate-source and Compose suite. |
| Deletion cancellation | Gap | The confirmation and remaining-path result UI are covered by Compose, but a live MediaStore approval/cancel flow was not available from the headless provider. |
| App sort modes and details/settings links | Pass | Connected intent-resolution tests resolved app details, storage settings, and cache controls; app sort coverage passed in JVM tests. |
| Process recreation | Pass | Force-stop and explicit MainActivity launch restored the dashboard and permission cards. |
| Portrait, landscape, and 200 percent text | Partial | Portrait and 200 percent Compose coverage passed for the primary Files workflow. A real 2400x1080 Files capture shows all threshold chips without clipping. Landscape and 200 percent coverage was not captured for every destination. |
| S25 shared-file scan | Pass | The physical S25 checked 16,418 shared files and found 68 files above 100 MB with nothing selected. |
| S25 duplicate scan | Pass | The physical S25 hashed 8 of 8 candidates, displayed an exact duplicate group, reported no read errors, and selected nothing. |
| S25 app inventory | Pass | The physical S25 reviewed 778 of 778 installed apps with all three sort controls present and no repository error. |
| S25 anchored deletion support | Pass | A targeted non-UI instrumentation test asserted `SecureDirectoryStream` support on the physical shared-storage root. The temporary test package was removed afterward. |

The release script refuses instrumentation when any physical Android device is attached, targets one emulator through `ANDROID_SERIAL`, and resets only that emulator's display override, rotation lock, and font scale. This prevents a prior landscape capture from contaminating the test environment without risking an install on Moo's phone.

## Hardware result

The verified 0.1.0 debug APK is installed on Moo's Samsung Galaxy S25 Ultra running Android 16/API 36. All Files Access and Usage Access were granted for acceptance. Core scans and the non-destructive deletion capability probe passed. No file was selected, deleted, or uninstalled. Live deletion approval and cancellation remain a deliberate gap.
